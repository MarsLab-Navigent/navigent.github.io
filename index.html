Navigent

A Geometry-Grounded Agentic Framework for Vision Language Navigation

Abstract

Vision-and-Language Navigation (VLN) with general-purpose multimodal large language models (MLLMs) offers a flexible alternative to task-specific navigation policies, while reliable long-horizon execution remains challenging. Agents must track navigation progress, detect discrepancies between commanded and actual motion, and recognize when movement has passed relevant landmarks or entrances.

We present Navigent, an agentic VLN framework built around a frozen MLLM and a Geometry-Grounded Execution Critic (GEC). GEC performs two complementary checks: action-to-motion consistency, which evaluates measured displacement against commanded movement, and motion-to-landmark consistency, which tracks agent-selected visual anchors and entrance candidates in world coordinates. Detected discrepancies interrupt the remaining action sequence and trigger reobservation, local adjustment, or node-based recovery. Historical visual memory supports progress tracking across extended routes. An offline self-improvement procedure further analyzes successful and failed training trajectories to refine navigation prompts and GEC logic while keeping model weights fixed.

On the R2R-CE validation-unseen split (1,839 episodes) and RxR-CE validation-unseen split (3,669 episodes), Navigent achieves 84.0%/86.0% SR and 72.9%/69.1% SPL, respectively, demonstrating the value of geometry-grounded execution verification for reliable agentic navigation.

Method

Given a natural-language route instruction, Navigent uses successive visual observations to choose movement commands and decide when to stop at the described destination. The method combines uniform historical visual memory with a Geometry-Grounded Execution Critic (GEC) and node recovery, while self-improvement refines navigation prompts and GEC logic.

Visual memory supplies the current observation and up to eight images sampled across the executed route. The agent predicts a short action sequence, while GEC monitors measured execution and local visual anchors. A detected discrepancy interrupts the remaining sequence; the agent then reobserves and chooses a local adjustment or a return to a visited node. The selected version remains fixed during navigation evaluation, while observation memory and execution state continue to update.

Navigation Context and Execution

Following a route requires relating the current scene to previously encountered landmarks and branches. Navigent retains a chronological observation archive and uniformly samples it at each decision, allowing the agent to inspect earlier route segments within a fixed budget of newly attached images. The current observation is outside the eight-frame history budget. The instruction enters the first decision and later decisions continue the same episode conversation. Navigation state records the starting pose, trajectory, visited nodes, traversed connections, return-path lengths, relative return bearings, heading, previous primitive counts, and blocked status.

Geometry-Grounded Execution Critic and Node Recovery

The agent predicts discrete forward and turning commands, or STOP, and executes a bounded prefix before obtaining a new observation. Each forward primitive is checked against its measured displacement. A depth precheck estimates near-field clearance before forward execution; measured motion checks detect insufficient forward progress, persistently small displacement, negative forward progress, or excessive lateral displacement. Local visual anchors track the distance and bearing of selected targets in world coordinates, while entrance candidates support entrance monitoring. When a discrepancy is detected, the remaining primitives are discarded and the agent receives a fresh observation, updated self-pose, primitive counts, and blocked status to choose a local adjustment or return to a visited node.

Self-Improvement

Completed training episodes are used for offline self-improvement of navigation prompts and GEC implementation while the MLLM weights remain fixed. Successful and failed trajectories provide observations, model responses, executed primitives, and measured motion for failure diagnosis. Three candidate patches are proposed from the same parent version, evaluated on the fixed training set, and compared by repairs minus regressions. Only a candidate with positive net gain is carried forward; otherwise the current version is retained. The selected prompt and GEC implementation are then fixed for navigation evaluation.

Real-world deployment

We evaluate Navigent on an AgileX SCOUT MINI mobile robot with an Intel RealSense D456 depth camera. Each of two indoor tasks and four outdoor tasks is attempted five times. A trial succeeds only when the robot executes STOP within 1 m of the designated target.

The indoor evaluation tests approaching a black cylinder followed by a blue cylinder, and shuttling between the two cylinders. The outdoor evaluation tests a gray chair, a green trash bin, the second white pillar after a corridor turn, and the route from the water dispenser to the green bin. Navigent completes 27 of 30 trials, for 90.0% SR.

The critic links commanded actions to measured motion and target geometry. With the prompt fixed, adding the critic and route review improves SR by 5 points and SPL by 2.8 points, while reducing NE from 4.09 m to 3.54 m. This comparison isolates the execution-monitoring contribution on Open-Nav100.

Pose and node records provide state for ordinary decisions and recovery. The executor still retains geometric feedback in every row. Without pose, NE improves despite lower SR and SPL, so lower navigation error alone does not imply better task completion.

Conversation Continuity

Continuing the episode conversation preserves route context. Single-turn evaluation keeps the instruction and sampled images but resets the dialogue at every decision. SR falls from 82% to 69%, SPL from 72.3% to 60.1%, OSR from 85% to 71%, and NE rises from 3.54 m to 4.47 m. Visual history alone therefore does not recover the benefit of a continuing conversation.
